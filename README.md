# Ayung Printing

A company profile website for **Ayung Printing**, a print shop. It introduces the business, lists its services and products, shows past work, and tells customers how to get in touch.

This was a team project for a web programming course.

## What's on the site

- **Home** with a big call to action
- **Services**: digital printing, offset printing, and large-format printing
- **Products**: flyers, business cards, vinyl banners, custom T-shirts, stickers, and event invitations
- **Portfolio**: six example projects, each with its own detail page
- **About**, **testimonials**, and **contact** sections, plus contact info and accepted payment methods in the footer
- Light and dark mode, and a layout that works on phones

## Tech stack

PHP, HTML, Tailwind CSS, JavaScript

## Getting started

You need PHP 7.4 or newer.

```bash
php -S localhost:8000
```

Then open http://localhost:8000. You can also put the folder in XAMPP's `htdocs`.

## Project structure

| Path | What it is |
| --- | --- |
| `index.php` | The main landing page |
| `menuportofolio/` | Portfolio detail pages (`portofolio1.php` to `portofolio6.php`) |
| `assets/js/portofolio.js` | Fills in the portfolio detail pages |
| `assets/css/style.css` | Extra styles |
| `photo/` | Images |
